About Wayback Master

Wayback Master is a powerful tool designed for researchers, security analysts, and developers to efficiently explore historical web content using the Wayback Machine. This framework enables targeted filtering of archived URLs based on file extensions and sensitive JavaScript file names that are defined and managed through the database.

🔍 Core Functionalities

  • Dynamic Extension Management: The framework allows users to add, update, or delete file extensions and sensitive JS file names used for filtration via a CRUD interface.
  • Archived URL Collection: When a domain is submitted, the system uses curl to query the Wayback Machine CDX API, retrieving archived URLs related to the target domain.
  • Multi-threaded Filtration: URLs are processed in parallel using multi-threading to filter them based on the extensions and JavaScript filenames stored in the database.
  • Structured Storage: Filtered results are saved and categorized by domain and extension, allowing easy browsing via the dashboard.
  • Wayback Archive Access: Each result includes a button to directly open the archived version of the file via the Wayback Machine.

📂 How It Works

  1. A user enters a domain name in the interface.
  2. The system sends a request to the Wayback Machine and downloads all associated URLs into a temporary file.
  3. The framework reads the file and checks if the URLs end with any of the extensions or sensitive JavaScript filenames stored in the database.
  4. Matched URLs are saved and linked to the domain in the database for future access.
  5. The user can view the filtered data categorized by extension, and click to explore the archived versions on the Wayback Machine.

📁 Supported File Types

Users can manage an extensive list of file extensions such as:

  • .pdf
  • .zip
  • .js
  • .config
  • .env
  • .docx
  • .xlsx
  • .tar
  • .bak
  • .crt
  • config.js
  • secrets.js
  • api_keys.js
  • tokens.js
  • cookies.js

This flexibility makes Wayback Master ideal for sensitive file hunting, archival data research, and historical web application analysis.
